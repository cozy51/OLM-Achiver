PDF

Outlook Mail Archiver

Outlook のメールを、元メールへのリンク付き PDF として保存する Edge 拡張機能

対象ブラウザー
Microsoft Edge
対象サービス
Outlook on the web（ブラウザー版 Outlook）
できること
開いているメールを1クリックで PDF 化し、決まった規則のファイル名で保存する

1この拡張機能でできること

ブラウザーで開いている Outlook のメールを、そのまま PDF ファイルとして保存します。手作業での印刷設定やファイル名の入力は不要です。

  • 元のメールへ戻れる — PDF の先頭に、そのメールを Outlook で開くリンクが入ります。
  • ファイル名が自動で決まる — 差出人・受信日時・件名から組み立てるため、フォルダー内で並べたときに探しやすくなります。
  • 差出人を自動で入力する — 画面から差出人を読み取り、入力欄へ自動的に入れます。
  • 添付ファイルが分かる — 添付ファイルの名前とリンクの一覧が PDF に入ります。
対応している Outlook のアドレス outlook.office.com / outlook.office365.com / outlook.cloud.microsoft
デスクトップ版 Outlook アプリでは使用できません。ブラウザーで Outlook を開いてください。

2インストール

最初に1回だけ行う作業です。以降は不要です。

  1. 拡張機能のフォルダーを、PC の分かりやすい場所に置く 例: C:\Users\（自分）\Documents\OutlookMailArchiver。 この後もフォルダーを参照し続けるため、置いたあとは移動や削除をしないでください。
  2. Edge のアドレス欄に edge://extensions と入力して開く
  3. 画面左下の「開発者モード」をオンにする
  4. 「展開して読み込み」を押し、手順1のフォルダーを選ぶ フォルダーの中にある manifest.json が見えている階層を選択します。
  5. ツールバーに拡張機能のアイコンが出ることを確認する 見当たらない場合は、ツールバーのパズルピース型のアイコンを押し、一覧の中の 「Outlook Mail PDF Archiver」のピン留めをオンにしてください。
補足 ビルドやインストーラーの実行は不要です。edge://extensions の一覧にもツールバーにも、 専用のアイコンが表示されます。

3使い方

  1. Outlook で、保存したいメールを1通開く 一覧で選択して閲覧ウィンドウに表示された状態でも構いません。
  2. ツールバーの拡張機能アイコンを押す 差出人名が自動で入力されます。
  3. 差出人名を確認する 違っていれば、その場で直接書き換えられます。
  4. 「📩 このメールを PDF 保存」を押す
  5. 保存先を選ぶ ファイル名はあらかじめ入力されています。そのまま保存して問題ありません。

4保存されるファイル名

ファイル名は、差出人・受信日時・件名から自動で組み立てられます。

📩_山田 太郎 (Yamada,T.)_20260713_2041_月次報告の件.pdf

添付ファイルのあるメールは、先頭が 📩📎_ になります。 フォルダーの一覧で、PDF を開かずに添付の有無を見分けられます。

📩📎_山田 太郎 (Yamada,T.)_20260713_2041_月次報告の件.pdf
差出人
拡張機能の画面で確認した差出人名がそのまま入ります。
受信日時
PDF を作った時刻ではなく、メールに表示されている受信日時（年月日＋時分）です。
件名
先頭の RE: FW: 返信: 転送: は自動的に取り除かれます。
記号について 項目の区切りには _（アンダースコア）を使います。そのためファイル名に使えない文字 （\ / : * ? " < > |）は -（ハイフン）へ置き換えます。
例: 差出人が Ito Takeshi / 伊藤剛 の場合 → Ito Takeshi - 伊藤剛

5できあがった PDF について

PDF の先頭には、そのメールを Outlook で開くためのリンクが入ります。あとから「元のメールを確認したい」というときに使えます。

リンクを新しいタブで開きたいとき リンクを Ctrl キーを押しながらクリックしてください（右クリックから「新しいタブで開く」でも同じです）。
そのままクリックすると、PDF を表示していた画面が Outlook に切り替わります。 どちらの動作になるかは PDF を開いているソフト側が決めているため、PDF ファイル側では指定できません。

添付ファイルのあるメールでは、件名の下に 添付ファイルの一覧 が入ります。

OneDrive・SharePoint のファイル
ファイル名がそのファイルを開くリンクになります。その下にリンク先が文字でも書かれています （紙に印刷したときのためです）。
メールに直接付いているファイル
ファイル単独の URL が存在しないため、ファイル名だけが並びます。 ファイルそのものは、ページ先頭のリンクから元のメールを開いて保存してください。
添付されたメール（Outlook アイテム）
メールにメールが添付されている場合も1件として数えます。 ファイル名の代わりに、そのメールの件名が並びます。
補足 PDF に残るのはファイルの名前とリンクです。ファイルの中身は PDF には含まれません。

6困ったときは

起きていること 対処
「デバッガーがこのブラウザーに接続しました」という通知が出る 正常な動作です。PDF を作るための機能を使っている間だけ表示され、自動的に消えます。そのままお使いください。
印刷の画面が出てきた 組織のセキュリティ設定により、PDF 機能へ直接つなげなかった場合の動作です。 「プリンター」の欄で PDF として保存 を選べば、同じ内容の PDF を保存できます。
差出人名が自動で入らない Outlook の画面で差出人名をコピーし、貼り付けボタンを押してください。直接入力しても構いません。
添付ファイルの一覧が PDF に入らない Outlook の画面構成が変わると、添付欄を読み取れないことがあります。この場合も PDF の保存自体は成功し、 一覧だけが省かれます。拡張機能の画面に 添付欄は見つかりましたが、ファイル名を読み取れませんでした と 表示された場合は、その旨をお知らせください（画面構成の調査が必要です）。
「メールを1通開いてから再実行してください」と出る メールの一覧だけが表示されている状態です。対象のメールを開いてから、もう一度実行してください。
「個別URLを取得できませんでした」と出る メール一覧で対象のメールを選択し直してから、もう一度実行してください。
その他のエラーが出た メッセージの先頭に 【失敗箇所: ○○】 と表示されます。この部分を添えて連絡してください。 どの段階で止まったかが分かります。
うまく動かないときにまず試すこと edge://extensions を開き、この拡張機能のカードにある更新（↻）ボタンを押してから、 Outlook のページを再読み込みしてください。多くの不具合はこれで解消します。

Outlook Mail Archiver 利用マニュアル / Outlook の画面構成が変更された場合、メール情報を読み取れなくなることがあります。
